# KeePass Sync personal

Sitio informativo para la pantalla de autorización OAuth de una utilidad personal de sincronización de KeePass con Google Drive.

- Inicio: https://luis-knd.github.io/keepass-sync/
- Privacidad: https://luis-knd.github.io/keepass-sync/privacidad.html

Contiene únicamente HTML y CSS. No necesita dependencias ni recopila datos mediante formularios, analítica o scripts.

Publicación: GitHub Pages desde `main`, carpeta `/`.
